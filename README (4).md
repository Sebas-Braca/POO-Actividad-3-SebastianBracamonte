## Descripcion

Este repositorio contiene la solucion de los dos ejercicios de la Actividad 3
de la asignatura Programacion Orientada a Objetos (2026-2S), tomados del libro
Ejercicios de programacion orientada a objetos con Java y UML de Leonardo Bermon
Angarita, desarrollados en Python con interfaz grafica (tkinter), incluyendo la
parte propuesta de cada ejercicio.

## Ejercicios

- Ejercicio 8.2 (pagina 483): componentes swing, calculo de notas
- Ejercicio 8.3 (pagina 495): gestion de eventos, figuras geometricas
